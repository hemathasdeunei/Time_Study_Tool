Getting Started

Welcome to Time Study Tool

A desktop app for industrial engineers to capture, organize, and export time studies on the shop floor.

Projects

Group your work by product line, department, or area. Each project has color-coded icons and owner info.

Operations

Each project contains operations — specific tasks or workstations you want to measure.

Time Studies

Multiple timed versions of the same operation. Track improvements over time with versioned studies.

Export to Excel

Export any recorded study to a formatted Excel workbook with color-coded summary rows.

Workflow at a glance: Create a Project → Add Operations → Attach a Step List → Add a Time Study → Record → Export. Use the sidebar to jump to any section below.

Projects

Projects are the top-level containers. Start here every time.

1
Open the Projects screen
When the app launches you land on the Projects screen. All your existing projects are shown as color-coded cards. If this is your first time, the screen will be empty.
2
Click "New Project"
Press the New Project button in the top-right corner. A modal dialog opens with the following fields:
• Project Icon — type 1–3 characters (auto-fills P1, P2… for each new project)
• Icon Color — pick from the 12-color palette (auto-cycles per project)
• Project Name — required, displayed on the card and in breadcrumbs
• Owner Name — optional, the person responsible
• Owner ID — optional, defaults to #### for easy replacement
Tip: The icon and color auto-fill each time you create a new project. You can override either one.
3
Click "Create Project"
The project card appears immediately. Click it to open the Operations screen for that project.
4
Edit or delete a project
Right-click any project card to open the context menu — options are Open, Edit, and Delete. Deleting a project removes all its operations, step lists, and time study data permanently.

Operations

An operation is a specific task, process, or workstation to be measured within a project.

1
Open a project
Click any project card from the Projects screen. You land on the Operations list for that project.
2
Click "Add Operation"
Fill in the operation details — Name, Department, Shift, Supervisor, and Engineer. These appear in your exported Excel reports.
Tip: Previously used supervisors and engineers are suggested in the dropdown as you type.
3
Reorder operations
Use the up/down arrows on the left of each row to change the order. The order is reflected in the Excel project template export.
4
Click an operation to open it
Clicking the operation row opens the Operation Detail screen where you manage Step Lists and Time Studies.
5
Export the full project template
Click the Export button in the Operations toolbar to download a blank TIME STUDY Excel template pre-filled with all operations in order, ready for manual data entry or distribution.

Step Lists

A step list defines the process steps that will be timed during recording.

1
Open an operation
From the Operations screen, click an operation row to open the Operation Detail page. The Step Lists panel is on the left side.
2
Create a new step list
Click + New Step List. Give it a name and add up to 15 steps. Each step has a name, an optional time allowance, and a VA/NA/NNA classification.
Tip: Click Load Default to quickly seed the list with a standard set of steps for this operation type.
3
View and edit steps
Click the eye icon on any step list card to preview all steps. Click the pencil icon to edit. Step lists can be reused across multiple time studies on the same operation.
4
Attach to a time study
When you create a Time Study (next section), you select which step list to use. The step list determines what gets timed during recording.

Time Studies

Time studies are versioned measurement sessions. Create multiple to track improvement over time.

1
Click "Add Time Study" on the Operation Detail page
The Add Time Study modal opens. Fill in the fields:
• Time Study Name — auto-fills as "Time Study 1", "Time Study 2", etc.
• Step List — select the step list to record against
• Observations — number of cycles to record (default 10, max 10)
• Operator — the person being studied
• Workstation — the location or machine
• Subject Type — Single (one unit) or Batch (multiple units per cycle)
• Notes — any free-text notes for context
2
The time study card appears in the list
Each card shows the version number, time study name, date, operator, step list, and observation count. The version increments automatically for each new study on the same operation.
3
Click "Record" to start capturing times
The Record button activates once a step list is attached. If a recording is already in progress, the button changes to "Continue" — letting you resume from where you left off.

Recording a Time Study

The recording screen captures cumulative and elemental times across all observations.

1
The recording screen opens full-screen
You see a grid: columns are observations (Obs 1, Obs 2 …), rows are your process steps. A running clock shows the current elapsed time.
2
Tap a step button to capture a timestamp
Each tap records the current time for that step in the active observation. The app automatically calculates the elemental time (difference from the previous tap).
Tip: Work through the steps in order from top to bottom, one cycle at a time. Each time you complete the last step, the next observation column activates automatically.
3
Complete all observations
Once all observation columns are filled, click Complete to finalize the recording. The time study card will show a green "Recorded" badge.
4
View the recorded data
Click the eye icon on a completed time study card to open the Read-Only View. You see all continuous and elemental times, lowest elemental per step, and a summary row.

Batch Time Studies

Use Batch mode when you are timing multiple units processed together in a single cycle.

1
Create a time study with Subject Type = Batch
In the Add Time Study modal, set Subject Type to Batch and enter the batch size (number of units processed per cycle).
2
Record start and end of each batch cycle
The batch recording screen shows two buttons per observation: Batch Start and Batch Finish. Tap Start when the cycle begins and Finish when it ends.
3
The app calculates per-unit cycle time
After all observations are complete, the Batch View shows the total cycle duration for each observation, the time per unit (÷ batch size), and the average cycle time across all observations.
4
Export the batch study
Use the Export button in the Batch View to download the results as a formatted Excel "Batch Time Observation Form" with green (start), red (finish), and gray (cycle time) rows.

Exporting to Excel

Three different export types, each producing a formatted .xlsx workbook.

1
Project Template Export
From the Operations screen, click Export in the toolbar. Generates a blank TIME STUDY template with all operations pre-listed in order — up to 10 observation columns, Average Time, Freq, PF&D%, Standard Time, UPH, and Units/Shift columns. Used for manual data collection or distribution.
2
Time Observation Form Export (Single)
From the Record View of a completed single time study, click Export. Generates a Time Observation Form with all recorded elemental times, lowest values highlighted, and adjustment columns. The Editor view's Export also produces an Analysis form with VA/NA/NNA classification.
3
Batch Time Observation Form Export
From the Batch View of a completed batch study, click Export. Generates a Batch Time Observation Form with start (green), finish (red), and cycle time (gray) rows for each observation, plus an average cycle column.
